# Weather Time-Series Analysis

This project analyzes historical hourly weather data using classical time- series methods and neural network models.

## Overview

The notebook explores temperature, pressure, and dewpoint dataover multiple days and applies forecasting techniques to predict future pressure values.

## Methods Used

- Exploratory Data Analysis(EDA)
- Autocorrelation and variogram analysis
- STL decomposition
- Holt - Winters exponential smoothing
- Recurrent Neural Network (RNN)
- Long Short-Term Memory (LSTM)

## Evaluation

Models are compared using error metrics (MAE, MSE, RMSE, MAPE) on a test period.

## Notes

- This was an academic project focused on understanding time-series behavior rather than production optimization.
- Neural network results vary due to random initialization and repeated training.
